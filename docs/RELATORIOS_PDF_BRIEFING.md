# Relatórios PDF + Excel + assistente pessoal

## Assistente pessoal (sem locadora)

| Pedido | O que faz |
| --- | --- |
| `bom dia` / `me atualiza` | Briefing (agenda 36h + gastos) |
| `balanço do mês` / `quanto sobrou?` | Receitas − despesas |
| `como estou de gastos?` | Insight vs mês anterior + dica |
| `me manda o relatório` / `PDF` / `Excel` | **PDF colorido + planilha CSV** (abre no Excel) |
| `me manda o relatório da semana` | PDF + Excel da agenda |
| `gastei R$…` / foto da nota | Lançamentos |
| `recebi 2000` | Receitas |
| meta / lembretes / lista / ICS | Já existentes |

## Formato dos arquivos

- PDF: cabeçalho, KPIs, seções
- Excel: CSV UTF-8 com `;` (abre no Excel BR sem instalar lib)
